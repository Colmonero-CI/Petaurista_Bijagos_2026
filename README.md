# Petaurista_Bijagos_2026
In this repository you can find the R scripts required for the str and mitochondrial DNA analyses of the paper "Genetic diversity and population structure of the spot-nosed monkey (Cercopithecus petaurista) of the Bijagós Archipelago, Guinea-Bissau, West Africaa" (Colmonero-Costeira et al., 2026; https://doi.org/10.1038/s41598-026-69922-4)

Please do acknowledge the authors of the scripts as stated.

The R scrip "petaurista_ICC_2026.R" can be used for:

STR loci:
*  Allelic richness
*  Pairwise FST
*  Principal components analysis (PCA)
*  Redundancy analysis (RDA)

mtDNA:
*  Multidimensional Scaling (MDS) 

Example files are included in the repository which matches the architecture required to use the R script.
